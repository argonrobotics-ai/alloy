# Security policy

Please do not report security vulnerabilities in public issues.

Report them privately through GitHub's "Report a vulnerability" button (Security tab of this repository). Include
what is affected, how to reproduce it, and the impact you expect. We aim to acknowledge reports within five working
days and to agree on a disclosure date with you.

Alloy runs user-supplied scenes, cards and plug-ins as Python code with your permissions; load only content you
trust.
